Reading the results

  • One row per live host: IP (with a device-type color dot), hostname, MAC, vendor, type, discovered services, latency (ping round-trip, else first TCP connect time).
  • Click a column header to sort by it; click again to reverse. The CSV export follows the same order.
  • The search field narrows the list (IP, hostname, MAC, vendor, services).
  • The ↔ toolbar button (Cmd+Shift+F) sizes every column to its contents without pushing any column out of view. Column dividers can be dragged to resize by hand.
  • HTTP/HTTPS services are links: clicking one opens the responding host in the browser.
  • Export saves the visible rows as CSV (disabled while a scan runs).
