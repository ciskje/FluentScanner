Scanning the network

  • Enter a start and end IP and press Start (Return works too). A single IP scans just that host.
  • Get IP fills the range of this machine's own subnet.
  • You can also type a CIDR range (192.168.1.0/24) or a full range (192.168.1.1-192.168.1.254, or 192.168.1.1-254). Network (.0) and broadcast (.255) addresses are never probed.
  • Discovery pings every address and probes common TCP ports in parallel; live hosts then get a full port sweep. The progress bar tracks discovery and a spinner marks a running scan.
  • Stop halts a running scan; rows found so far are kept. Results appear live, the moment each host answers.
