MAC addresses and vendors

  • MACs come from the local ARP table, which the ping sweep and the TCP connects populate. Responders still missing an entry get a targeted re-ping and an ARP re-read.
  • The vendor is the OUI prefix of the MAC (bundled IEEE table, works offline). The Type hint combines it with service clues (RDP/WinRM → Windows host, 9100 → Printer, 2049 → NAS, vendor names → NAS, IoT device, Router/AP…) and a ping-reply TTL guess (only 128 suggests Windows).
  • When the OUI says nothing, the HTTP Server header (already-open 80/8080) or the UPnP device description fills the brand slot instead.
