Colors and icons

  • The dot before each IP is the device type: Printer, NAS, Router/AP, Windows host, Raspberry Pi, Apple device, IoT device, PC (see the legend below the table).
  • Each vendor brand gets its own stable color in the Vendor column.
  • A shuffle icon marks a randomized (locally-administered) MAC: it carries no vendor and is never OUI-blamed.
  • The scanning host itself is always listed: bold row, computer icon, accent IP (yellow on dark, darker amber on light so it stays readable).
