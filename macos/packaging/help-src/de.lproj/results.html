Ergebnisse lesen

  • Eine Zeile pro aktivem Host: IP (mit Typ-Farbpunkt), Hostname, MAC, Hersteller, Typ, gefundene Dienste, Latenz (Ping, sonst erster TCP-Connect).
  • Klick auf die Kopfzeile sortiert die Spalte; nochmal kehrt um. Der CSV-Export folgt derselben Ordnung.
  • Das Suchfeld engt die Liste ein (IP, Hostname, MAC, Hersteller, Dienste).
  • Der ↔-Button (Cmd+Umschalt+F) passt jede Spalte an, ohne eine zu verdrängen. Trennlinien lassen sich von Hand ziehen.
  • HTTP/HTTPS-Dienste sind Links: ein Klick öffnet den Host im Browser.
  • Export speichert die sichtbaren Zeilen als CSV (während eines Scans deaktiviert).
