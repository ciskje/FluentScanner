Farben und Symbole

  • Der Punkt vor jeder IP ist der Gerätetyp: Printer, NAS, Router/AP, Windows host, Raspberry Pi, Apple device, IoT device, PC (siehe Legende unter der Tabelle).
  • Jeder Hersteller hat seine stabile Farbe in der Hersteller-Spalte.
  • Das Shuffle-Symbol markiert eine zufällige (lokal vergebene) MAC: ohne Hersteller, nie fälschlich zugeordnet.
  • Der scannende Host ist immer gelistet: fette Zeile, Computer-Symbol, betonte IP (Gelb in Dunkel, dunkleres Amber in Hell, damit lesbar).
