Couleurs et icônes

  • La pastille devant chaque IP est le type d'appareil : Printer, NAS, Router/AP, Windows host, Raspberry Pi, Apple device, IoT device, PC (voir la légende sous le tableau).
  • Chaque marque a sa couleur stable dans la colonne Fabricant.
  • L'icône shuffle signale une MAC aléatoire (localement administrée) : sans fabricant, jamais attribuée à tort.
  • La machine qui analyse est toujours listée : ligne en gras, icône d'ordinateur, IP accentuée (jaune en sombre, ambre en clair pour rester lisible).
