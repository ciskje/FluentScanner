Adresses MAC et fabricants

  • Les MAC viennent de la table ARP locale, remplie par le balayage ping et les connexions TCP. Tout répondant sans entrée reçoit un re-ping ciblé et une relecture ARP.
  • Le fabricant est le préfixe OUI de la MAC (table IEEE incluse, hors ligne). Le type combine OUI et indices de service (RDP/WinRM → Windows host, 9100 → Printer, 2049 → NAS, noms → NAS, IoT, Router/AP…) plus le TTL du ping (seul 128 suggère Windows).
  • Quand l'OUI se tait, l'en-tête HTTP Server (80/8080 déjà ouverts) ou la description UPnP remplit la marque à la place.
