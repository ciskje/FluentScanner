Lire les résultats

  • Une ligne par hôte actif : IP (pastille de type), nom d'hôte, MAC, fabricant, type, services trouvés, latence (ping, sinon premier TCP).
  • Un clic sur l'en-tête trie la colonne ; un autre inverse. L'export CSV suit le même ordre.
  • Le champ de recherche restreint la liste (IP, nom, MAC, fabricant, services).
  • Le bouton ↔ (Cmd+Maj+F) ajuste chaque colonne sans en faire sortir aucune. Les séparateurs se tirent à la main.
  • Les services HTTP/HTTPS sont des liens : un clic ouvre l'hôte dans le navigateur.
  • Export enregistre les lignes visibles en CSV (désactivé pendant l'analyse).
