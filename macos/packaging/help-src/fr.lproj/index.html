Aide de FluentScanner

FluentScanner trouve tous les appareils de votre LAN : découverte ping et TCP, balayage des ports, identification MAC et fabricant, noms d'hôtes. Choisissez un chapitre :

  • Analyser le réseau
  • Lire les résultats
  • Couleurs et icônes
  • Adresses MAC et fabricants
  • Noms d'hôtes
  • Réglages
  • Dépannage

Saisissez dans le champ de recherche du menu Aide pour chercher dans tous les chapitres. L'historique complet : menu Aide > Nouveautés.
